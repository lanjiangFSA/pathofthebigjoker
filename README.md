# 大怪路子 Web 版

> 初始版本：v0.1.0

一个无需安装的浏览器联机大怪路子牌桌。房主创建房间并分享六码房间号；人数不足六人时，空位会由 AI 自动补齐。

## 快速启动

需要 Node.js 18 或更新版本。在项目根目录执行：

```bash
node server.js
```

浏览器访问 `http://localhost:3000`。停止服务请在终端按 `Ctrl + C`。

## v0.1.0 功能

- Web 浏览器多人房间：创建、加入、邀请码复制与服务端实时同步。
- 六人、三副牌、红蓝交叉座位；未坐满时由 AI 补位。
- 单张、对子、三张，以及顺子、同花、葫芦、四带一、同花顺、五根。
- 牌序与展示：大怪 > 小怪 > 将牌 > A > K … > 3；手牌左大右小。
- 回合出牌、压牌、过牌与重新获得出牌权。
- 基于剩余对手人数的升级结算、庄家和将牌状态显示。

## 当前范围

本版本是可试玩的初始版本。怪牌可以补同点数牌型；怪牌参与顺子、同花等五路时的完整百搭声明规则，以及问牌/报牌规则，计划在后续版本完善。

## 免费部署

项目包含 `render.yaml`，可作为 Render Blueprint 部署：

1. 将此 Git 仓库推送到 GitHub。
2. 登录 Render，选择 **New → Blueprint** 并连接仓库。
3. 创建免费 Web Service；Render 会提供一个可分享的 HTTPS 地址。

注意：Render 免费实例在连续 15 分钟无访问后会休眠，首次重新访问约需一分钟唤醒。
