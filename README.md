# 大怪路子 Web 版

> 当前版本：**v0.6.0**

一个无需安装的浏览器联机大怪路子牌桌。房主创建房间并分享六码房间号；人数不足六人时，空位会由 AI 自动补齐。

## 快速启动

需要 Node.js 18 或更新版本。在项目根目录执行：

```bash
node server.js
```

浏览器访问 `http://localhost:3000`。停止服务请在终端按 `Ctrl + C`。本地可用 `npm test` 跑规则与回归用例。

## 功能概览

- Web 浏览器多人房间：创建、加入、邀请码复制与服务端实时同步；刷新可按本地会话自动回房。
- 等人阶段座位始终可见；房主可踢人；对局中退出可选「整桌中止」或「AI 接手」。
- 六人、三副牌、红蓝交叉座位；**六副一赛段**，赛段结束累计比分后随机重排真人座位并开新赛段（比分归零）。
- 庄家即本局首出，每局结束座位顺时针轮转；将牌固定为 **2**（无升级玩法/顶栏展示）。
- 单张、对子、三张，以及杂顺、同花、三带两、四带一、同花顺、五同。
- 牌序：大怪 > 小怪 > 将牌 > A > K … > 2；手牌按点数竖列；大小怪 **JOKER** 左上对齐（`J` 与点数同大，彩 / 灰）。
- 回合出牌、压牌、过牌；**首手 45 秒 / 之后 25 秒**倒计时仅在当前出牌座位头像旁。超时跟牌默认不出；首出超时打最小单张。
- 一方三家出完即结算；跟牌张数不够自动过；天王类必杀牌跳过围圈「不要」（座位旁保留上一手直到新出牌覆盖）。
- 红蓝比分赛段内累计；座位剩余张数仅在 ≤10 张时显示。
- 横屏优先环桌布局；座位旁只显示该座最新一手；中央仅保留状态提示文字。
- 牌桌 BGM 与音效（含轮到你「叮」）；默认音乐 10 / 音效 30；顶栏可分别调节。
- 昵称默认用上次填写；首次进入为「牌友」+ 随机字母。

规则对齐 `gamerules/howtoplay.md`；AI 配合对齐 `gamerules/howtocollabrate.md`（本版未改 AI 策略）。

## 免费部署

项目包含 `render.yaml`，可作为 Render Blueprint 部署：

1. 将此 Git 仓库推送到 GitHub。
2. 登录 Render，选择 **New → Blueprint** 并连接仓库。
3. 创建免费 Web Service；Render 会提供一个可分享的 HTTPS 地址。
4. 之后每次 `main` 有新提交，可在 Dashboard 查看自动部署，或手动 **Deploy latest commit**。

注意：Render 免费实例在连续约 15 分钟无访问后会休眠，首次重新访问约需一分钟唤醒；休眠或重新部署会清空内存中的房间。部署后请**强制刷新**浏览器缓存。
