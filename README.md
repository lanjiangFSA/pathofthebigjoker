# 大怪路子

一款可在浏览器中游玩的 6 人联机“大怪路子”扑克牌桌。创建者获得一个六码房间号，分享给 5 位朋友即可一起玩。

## 启动

需要 Node.js 18 或更高版本。在此目录执行：

```powershell
npm start
```

然后打开 `http://localhost:3000`。

## 和异地朋友联机

将项目部署到任一支持 Node.js 的托管服务（例如 Render、Railway 或 Fly.io），或使用安全隧道将本机的 3000 端口临时公开。朋友打开相同网址，输入你创建牌桌时显示的邀请码即可加入。

同一局域网内，也可以让朋友访问 `http://你的局域网IP:3000`（注意系统防火墙需允许 Node.js 访问）。

## 已实现规则

- 固定 6 人、3 副牌、红蓝两队交叉座位；每人 27 张。
- 将牌、轮流压牌、过牌与获得新一轮出牌权。
- 单张、对子、三张，以及顺子、同花、葫芦、四带一、同花顺、五根六类五路牌。

这是首版可联机原型。怪牌当前按其本身大小处理，尚未实现“怪作任意牌”的百搭声明与完整升级结算；这两项适合在首轮试玩后按你们常用的桌规补齐。
