# 大怪路子 Web 版

> 当前版本：**v0.5.2**

一个无需安装的浏览器联机大怪路子牌桌。房主创建房间并分享六码房间号；人数不足六人时，空位会由 AI 自动补齐。

## 快速启动

需要 Node.js 18 或更新版本。在项目根目录执行：

```bash
node server.js
```

浏览器访问 `http://localhost:3000`。停止服务请在终端按 `Ctrl + C`。本地可用 `npm test` 跑规则与回归用例。

## 功能概览

- Web 浏览器多人房间：创建、加入、邀请码复制与服务端实时同步。
- 六人、三副牌、红蓝交叉座位；未坐满时由 AI 补位（主攻/辅助分工）。
- 单张、对子、三张，以及杂顺、同花、三带两、四带一、同花顺、五同。
- 牌序：大怪 > 小怪 > 将牌 > A > K … > 2；手牌按点数竖列，顶条横排点数/花色；大怪彩色小丑、小怪黑白小丑。
- 自由牌可组非单张牌型；五路中按最小补齐，并优先判成更大牌型。
- 回合出牌、压牌、过牌与重新获得出牌权；**15 秒倒计时**，超时自动出最小合法牌或过牌。
- 创建房间可选「启用将牌升级」（默认关闭，将牌固定为 2）。
- 红蓝比分从 0 按局累计；座位剩余张数仅在 ≤10 张时显示。
- 横屏优先环桌布局（相对自己旋转座位）；本轮「不出」标在座位旁。
- 桌面显示当前最大出牌；本轮每人出牌/不出记录保留到轮次结束。
- 座位显示「你 / 队友」；AI 出牌间隔约 2 秒；局末可「开始下一局」。

规则对齐 `Skills/howtoplay.md`；AI 配合对齐 `Skills/howtocollabrate.md`。

## 免费部署

项目包含 `render.yaml`，可作为 Render Blueprint 部署：

1. 将此 Git 仓库推送到 GitHub。
2. 登录 Render，选择 **New → Blueprint** 并连接仓库。
3. 创建免费 Web Service；Render 会提供一个可分享的 HTTPS 地址。
4. 之后每次 `main` 有新提交，可在 Dashboard 查看自动部署，或手动 **Deploy latest commit**。

注意：Render 免费实例在连续约 15 分钟无访问后会休眠，首次重新访问约需一分钟唤醒；休眠或重新部署会清空内存中的房间。
