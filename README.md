# 大怪路子（Web 版）

浏览器联机的 6 人大怪路子牌桌。无需安装：房主创建房间，分享六码房间号即可邀请朋友。人数不足时，空位由 AI 自动补齐。

## 本地启动

需要 Node.js 18 或更高版本：

```powershell
cd D:\P0712\4
node server.js
```

访问 `http://localhost:3000`。

## 已实现玩法

- 6 人、3 副牌、红蓝交叉组队，任意人数可由 AI 补足至 6 人。
- 单张、对子、三张，及顺子、同花、葫芦、四带一、同花顺、五根六种五路牌。
- 怪牌可补同点数的对子、三张、四带一、葫芦和五根；小怪不能替作大怪。
- 服务端 AI：只使用自己的手牌，按“最小可压牌优先”的策略出牌。
- 每局结算后按对方剩余人数升级；若获胜方不是当前庄家，则少升一级。页面显示两队等级、庄家与将牌。

## 免费部署到 Render

项目已带有 `render.yaml`。操作如下：

1. 将 Git 仓库推送到你的 GitHub 账户。
2. 登录 Render，选择 **New → Blueprint**，连接该 GitHub 仓库。
3. 确认免费 `dagua-luzi` Web Service 并创建。
4. Render 部署完成后会提供 `https://…onrender.com` 地址，分享此地址给朋友。

免费服务在连续 15 分钟没有访问后会休眠；下次打开需等待约一分钟唤醒。对好友小范围试玩是合适的。
